# Panel de hábitos del día

Aplicación desarrollada en Flutter para registrar hábitos diarios, consultar el progreso, definir una meta, activar el modo enfoque y guardar una nota.

## Funcionalidades
- Marcar y desmarcar cinco hábitos.
- Consultar el progreso diario.
- Establecer una meta.
- Activar el modo enfoque.
- Guardar una nota.
- Abrir una pantalla de resumen.

## Requisitos
- Flutter SDK compatible con Dart 3.13.1 o superior.
- Dart SDK.

## Ejecutar
```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

## Documentación
Los documentos de pruebas y alcance se encuentran en `docs/`.

## Nota sobre Firebase
La versión actual del repositorio no contiene una integración Firebase configurada. La práctica requiere agregar y probar al menos un servicio Firebase real; esto queda pendiente de configurar con el proyecto Firebase y sus archivos de plataforma correspondientes.
