# 02. Mapa de flujos críticos

## Flujo 1: Consultar hábitos
El usuario puede abrir la aplicación y consultar sus hábitos guardados en Firestore.

## Flujo 2: Completar un hábito
El usuario puede marcar un hábito como completado y guardar el cambio en Firestore.

## Flujo 3: Consultar resumen
El usuario puede abrir la pantalla de resumen y visualizar el progreso de sus hábitos.

## Flujo 4: Reiniciar el día
El usuario puede reiniciar los hábitos y guardar el nuevo estado en Firestore.

## Flujo 5: Conservar los cambios
El usuario puede actualizar la aplicación y consultar los cambios que ya fueron guardados.
