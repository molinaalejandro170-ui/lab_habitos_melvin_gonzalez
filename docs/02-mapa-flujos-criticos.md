# Mapa de flujos críticos

1. El usuario puede abrir el panel y visualizar sus cinco hábitos.
2. El usuario puede marcar o desmarcar un hábito y ver actualizado el progreso.
3. El usuario puede modificar la meta diaria y ver si la alcanzó.
4. El usuario puede guardar una nota del día.
5. El usuario puede abrir la pantalla de resumen y regresar al panel.
