# 05. Reflexión final

Durante esta práctica se integró Firebase Core y Cloud Firestore en una aplicación Flutter de hábitos.

Se comprobó que la aplicación puede consultar, guardar y actualizar los hábitos en Firestore. También se verificó la persistencia de los cambios, el funcionamiento de la pantalla de resumen y el reinicio de los hábitos.

Se implementaron cinco pruebas unitarias y dos pruebas de widget para comprobar la lógica de progreso, la carga y actualización de hábitos y la pantalla de resumen. Todas las pruebas automatizadas finalizaron correctamente.

Además, se ejecutó flutter analyze y el resultado fue No issues found.

Como aprendizaje, se comprendió la importancia de probar las funciones principales, utilizar repositorios falsos para las pruebas, corregir incidencias y documentar los resultados.

Queda pendiente comprobar el comportamiento de la aplicación cuando no hay conexión con Firestore.
