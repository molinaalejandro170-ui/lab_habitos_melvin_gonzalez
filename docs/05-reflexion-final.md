# 05. Reflexión final

Durante esta práctica se integró Firebase Core y Cloud Firestore en una aplicación Flutter de hábitos.

Se comprobó que la aplicación puede consultar y guardar los hábitos en Firestore. También se verificó el funcionamiento de la pantalla de resumen y el reinicio de los hábitos.

Se implementaron pruebas unitarias para la lógica de progreso y una prueba de widget para el resumen. Todas las pruebas automatizadas ejecutadas finalizaron correctamente.

Además, se ejecutó flutter analyze y el resultado fue No issues found.

Como aprendizaje, se comprendió la importancia de probar las funciones principales, corregir incidencias y documentar los resultados.

Queda pendiente comprobar el comportamiento de la aplicación cuando no hay conexión con Firestore.
